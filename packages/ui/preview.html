Cách dùng

Kênh CDN giống Bootstrap: một <link> cho CSS, thêm <script defer> chỉ khi dùng Tabs, Select, Combobox, Command, Toast, Sidebar hoặc Slider. Project đã có Tailwind thì import bản source.

<script src="https://cdn.jsdelivr.net/npm/@auvyx/ui@0.1.0/dist/auvyx.min.js" defer></script>  <!-- tùy chọn -->

<html class="dark" data-theme="ocean">  <!-- dark mode + brand theme = chỉ CSS variables -->
