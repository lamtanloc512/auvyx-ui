HTML structure

<dl class="properties">
The list. Rows stack label over value when it is narrower than 18rem.
<div>
A row.
<dt>
The label, with an optional leading <svg>.
<dd>
The value. Long unbroken values (ids, URLs, paths) wrap instead of overflowing.
<button> or [data-actions] last in the <dd> Optional
A row action, such as a copy button (data-copy-text, in auvyx.min.js). It sits at the end of the row, beside the value; wrap the value in an element so it wraps on its own.
