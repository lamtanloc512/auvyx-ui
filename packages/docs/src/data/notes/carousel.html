HTML structure

<section class="carousel">
The root. Give it aria-roledescription="carousel" and an aria-label. data-items="2|3|4" or --per-view sets the slides per view, --carousel-gap the gap, data-orientation="vertical" scrolls vertically.
<ol> / <ul> with <li> slides
The scroller. Each slide gets aria-roledescription="slide" and a label such as "2 of 5". Without JavaScript it scrolls, snaps and swipes; supporting browsers add native arrows (::scroll-button) and, with data-markers, dots.
[data-carousel="prev"], [data-carousel="next"], [data-carousel="play"]
Buttons you provide (any button style). Prev and next sit over the slides; move them with --carousel-controls-inset and --carousel-controls-top. The play button holds two icons: the first shows while paused, the second while playing.
[data-carousel-dots], [data-carousel-counter]
An empty element filled with one dot per page, and an element that shows "2 / 5".
a[data-lightbox="group"]
A link to the full image. With JavaScript it opens a full-screen viewer with every link of the same group (swipe, drag, arrow keys, click to zoom); data-caption or title sets the caption. Without it, the link opens the image.

JavaScript API

js/carousel.min.js (also in auvyx.min.js) is optional. Once it runs, the native arrows and markers make way for your controls.

data-loop
Wrap from the last page to the first and back.
data-autoplay="5000"
Advance every n ms (implies loop). Pauses while hovered or focused, while the tab is hidden, and starts paused for prefers-reduced-motion.
data-no-drag
Turn off mouse dragging (touch always swipes).
data-carousel-for="id"
Makes this carousel the thumbnail strip of carousel id: clicking a thumbnail shows that slide, and the active thumbnail follows the main carousel.
goTo(page), goToSlide(index), next(), prev(), play(), pause()
Methods on the root element.
carousel:change
Fired on the root when the page changes; detail is { page, slide, pages }.

The active slide gets data-active. Keyboard: focus the slides and use the arrow keys, Home and End.
