HTML structure

<div class="alert">
Main container. Use data-variant="destructive" for errors, and success, warning or info for the other states. Their colors are the --success, --warning and --info theme tokens (light and dark), which a theme can override like any other.
<svg> Optional
The icon.
<h2>
The title.
<section> Optional
The description.
<footer> Optional
The action region, aligned to the inline end of the alert. Put the action element inside it, such as a button or link.
