Upstream builds this with TanStack Table in React. Auvyx keeps the rows as server-rendered <tr> elements and the <auvyx-data-table> element only reorders, hides and annotates them. Without JavaScript it is a plain table.

HTML structure

<auvyx-data-table class="data-table">
Root. Optional attributes: data-page-size (rows per page), data-grid (one tab stop; arrow keys, Home/End, Ctrl+Home/End and PageUp/PageDown move between cells; Space toggles the row), data-sticky (sticky header when the table wrapper has a max height), data-mode="server" with data-total (see below).
<input type="search" data-filter>
Text filter. data-filter="name,email" limits it to those columns (keys or indexes).
<input type="checkbox" data-facet="status" value="Paid">
Faceted filter: values in the same column are OR'ed, columns are AND'ed. Matches the cell's data-value or text. <span data-facet-count="status"> shows how many are active.
<input type="checkbox" data-column="email" checked>
Column visibility toggle.
<th aria-sort="none" data-key="amount" data-type="number"><button>
Sortable header. data-key names the column for state, facets and toggles; data-type="number" sorts numerically. Start with aria-sort="ascending" for an initial sort.
<tr data-key="INV001">
Data row. data-key (or id) identifies it in state.selected and events. <td data-value> overrides the text for sorting and facets.
<td data-editable>
Inline editing: double-click, Enter or F2 opens an input; Enter or blur commits, Escape cancels. Fires cellchange.
<button data-expand aria-expanded="false"> + <tr data-detail hidden>
Expandable row. The detail row directly follows its row and moves with it when sorted.
input[data-select-all], input[data-select]
Row selection. Shift-click selects a range.
[data-selected-count], [data-page-status], select[data-page-size], [data-page="first|prev|next|last"], [data-reset]
Footer and toolbar hooks. Counters accept data-template with {selected}, {total}, {page}, {pages}. [data-reset] is hidden while there is nothing to reset.

Server-side data

With data-mode="server" the element leaves rows in place and emits statechange; render the requested page, replace the <tbody> rows, set data-total and call refresh().

table.addEventListener('statechange', async (e) => {
  const html = await fetch('/invoices?' + new URLSearchParams({ state: JSON.stringify(e.detail) })).then((r) => r.text());
  table.querySelector('tbody').innerHTML = html;
  table.dataset.total = '128';
  table.refresh();
});

JavaScript API

API Type Description
table.state Property Read or write { query, sort: { column, direction } | null, filters: { [column]: string[] }, page, pageSize, hiddenColumns, selected }. Writes merge, update the controls and emit statechange.
table.refresh() Method Re-read rows after replacing <tbody> content.
statechange Event Sort, filter, facet, page, page size or column visibility changed; detail is the state.
selectionchange Event detail.rows lists the selected rows.
cellchange Event Cancelable. detail: { row, rowKey, column, value, previous }. Call preventDefault() to reject the edit or to render the value yourself.
