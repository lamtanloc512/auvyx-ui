The board is CSS only. For drag and drop, wrap it in <auvyx-sortable> and load js/sortable.min.js; that module is not part of auvyx.min.js.

HTML structure

<div class="kanban"> or <auvyx-sortable class="kanban">
Board. Columns scroll horizontally; set --kanban-column for the minimum column width.
<section aria-labelledby="…">
A column: a <header> with its heading, then an <ol> of cards. [data-drag-count] in the header shows the number of cards and updates after a drop.
<li>
A card. Wrap its content in one <a> to make the whole card a link. Add [data-drag-handle] inside to drag only by the handle, data-drag-disabled to pin it.

JavaScript API

API Type Description
sort Event Cancelable. detail: { item, from, to, index, previousIndex } after a drop; preventDefault() puts the card back (for example when the server rejects the move).
sortable.refresh() Method Re-scan after adding columns or cards.
Keyboard Behavior Space picks up the focused card, Up/Down move it, Left/Right move it to the next column, Space or Enter drops, Escape cancels. Moves are announced to screen readers.
