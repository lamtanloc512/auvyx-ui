Add class="spinner" with role="status" and aria-label="Loading" to a loader icon (any inline SVG turns), or to an empty <span>, which draws a ring in the current text color. data-size="sm|lg|xl" sets 0.75, 1.5 or 2rem (default 1rem); inside a button, badge or input group it takes their icon size. Under prefers-reduced-motion: reduce it pulses instead of turning.
