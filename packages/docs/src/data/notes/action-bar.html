CSS only: your code shows the bar (remove hidden) when rows are selected, updates the count, and hides it again.

HTML structure

<div class="action-bar" role="region" aria-label="Selection" hidden>
Fixed at the bottom center of the viewport, above the safe area (env(safe-area-inset-bottom)), at most the viewport width minus 2rem; it scrolls sideways if the actions do not fit. It rises in when shown, without movement under reduced motion. data-position="sticky" keeps it at the bottom of its scrolling container instead (a table in a panel).
<output>
The count, such as "3 selected". As a live region it announces changes.
<button class="btn">
The actions, usually data-variant="ghost" data-size="sm", and a clear-selection button last. Put a button's label in a <span> after its icon: below 40rem only the icon shows and the label remains its accessible name.
<hr> Optional
A vertical divider between groups of actions.
