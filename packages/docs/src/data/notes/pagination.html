HTML structure

<nav class="pagination" aria-label="Pagination">
The landmark. Centered, or spread to both ends when it has a summary.
<p>, <small> or <output> Optional
A summary such as "11–20 of 42".
<ul> + <li>
The pages.
<a class="btn" data-variant="ghost" data-size="icon">
A page. The current one has aria-current="page" and data-variant="outline". aria-disabled="true" on a link (or disabled on a button) makes it inert, such as Previous on the first page.
<span aria-hidden="true"> Optional
An ellipsis between page ranges.
